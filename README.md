# Twitter-Sentiment-Analysis-LSTM-with-Class-Weights
Build, evaluate, and (later) deploy a sentiment analysis model on Twitter_Data.csv using an LSTM-based deep learning model.  We follow this workflow:  Dataset overview and basic EDA Text cleaning (NLP preprocessing) Train–test split Tokenization and sequence padding Building a BiLSTM model in TensorFlow/Keras Training with EarlyStopping
